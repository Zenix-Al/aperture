# Reading Desk

Start with [Run and build Reading Desk](quickstart.md). This project demonstrates routes, feature lifecycle, settings, a custom tab, themes and a bookmark add-on using the shared architecture.

For your own site, follow [Create a site project](../guides/create-project.md), [architecture](../guides/architecture.md) and [build/test](../guides/build-test.md). Use [troubleshooting](troubleshooting.md) for local installation and storage issues.

Current browser fixtures do not establish installed-manager compatibility.
